# **<center>Ejercicios de Programación - Teórica y Práctica**

Este repositorio contiene el desarrollo del taller de nivelación, el cual está dividido en dos partes:

1. Parte teórica (conceptos sobre Git y programación en Java).
2. Parte práctica (implementación de programas en Java utilizando estructuras de control).

El objetivo del repositorio es reforzar los conocimientos fundamentales de control de versiones con Git y los conceptos básicos de programación en Java.

## **Contenido**

### **- Investigación sobre Git**
Se desarrollaron los siguientes temas:

- ¿Qué es un repositorio y cómo se diferencia de un proyecto normal?
- Áreas principales de Git (Working Directory, Staging Area y Repository).
- Representación interna de Git (blob, tree, commit y tag).
- Creación y estructura de un commit.
- Diferencias entre git pull y git fetch.
- Uso de ramas (branch) y gestión de punteros.
- Proceso de merge y resolución de conflictos.
- Funcionamiento del staging area (git add).
- Uso del archivo .gitignore.
- Diferencias entre commit --amend y un nuevo commit.
- Uso de git stash.
- Mecanismos para deshacer cambios (reset, revert, checkout).
- Configuración de remotos (origin y upstream).
- Comandos para inspeccionar historial (git log, git diff, git show).

### **- Investigación sobre programación**
Se desarrollaron los siguientes conceptos:

- Tipos de datos primitivos en Java.
- Estructuras de control (if, else, switch, for, while, do-while).
- Importancia de nombres significativos en variables y métodos.
- Programación Orientada a Objetos (POO).
- Cuatro pilares de la POO:
    - Encapsulamiento.
    - Abstracción.
    - Herencia.
    - Polimorfismo.
- Herencia en Java.
- Modificadores de acceso (public, private, protected, default).
- Variables de entorno.

### **- Calculadora básica**
Permite realizar operaciones de suma, resta, multiplicación y división utilizando estructuras de control.

### **- Contador de vocales y consonantes**
Cuenta el número de vocales y consonantes en una palabra ingresada por el usuario.

### **- Invertir una cadena**
Invierte una cadena de texto ingresada por el usuario.

## **Instrucciones**

1. Clona el repositorio.
2. Navega a cada directorio de ejercicios.
3. Compila y ejecuta los archivos `.java` para probar los ejercicios.
